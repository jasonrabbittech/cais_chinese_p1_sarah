## 场景验证

### 场景 1: 诗人 CRUD + 图片上传（FR-002/003/004/005）

1. admin「內容管理」→ 新增诗人（王維/唐/bio/🏔️/語言=古代語言/tone/personality）
2. **上传头像**（选一张 ≤2MB jpg）→ 保存成功
3. 学生端（未发布时不可见）→ 后台**发布** → 学生端诗人标签出现「🏔️ 王維」（**图片头像**渲染，非 emoji）
4. 编辑：语言风格切换为「香港本地粵語」→ 保存
5. 上传超 2MB 或非图片文件 → 前端拦截提示
6. 「高級」折叠区：展开可见自动生成的完整 prompt → 手动改写保存 → DB system_prompt 为覆写值；再改 tone/personality 保存 → prompt **不被重写**（D10 保护语义）
7. 存量 4 诗人（无 avatar_url）→ 学生端仍显示 emoji（回退链，research D9）

**DB 抽查**: `SELECT name, language_style, avatar_url FROM poets WHERE name='王維';` — avatar_url 为**相对路径**（无域名）。

### 场景 2: Storage 公开可访问（research D1）

```bash
curl -s -o /dev/null -w "%{http_code}" "${SUPABASE_URL}/storage/v1/object/public/poet-assets/poets/{id}/avatar.jpg"
# 预期 200
# 未登录上传（curl 无 JWT）→ 403
```

### 场景 3: 删除保护（FR-007）

1. 删除有留言的诗人（蘇軾）→ **409**「有 N 條學生留言…」提示
2. 删除无留言的新诗人（王維，先删其留言或从未有留言）→ 成功
3. 删除有留言的作品 → 409；无留言作品 → 成功

### 场景 4: 语言风格即时生效（FR-005，research D2）

1. 王維语言风格 = 粵語 → 学生端留言「你好」→ AI 回复含粤语口语（你好吖/多謝/唔該类）
2. 切回現代語言 → 新留言 → 回复为现代白话
3. 存量诗人（未配置 tone/personality）→ AI 回复风格与 004 之前**一致**（向后兼容）

### 场景 5: 龙虎榜（FR-010）

1. 制造数据：学生 A 3 留言+2 追问、学生 B 2 留言、学生 C 1 追问
2. admin「統計」→ 龙虎榜：A(5) > B(2) > C(1)
3. 并列时按首次留言时间先后
4. 学生端**无**龙虎榜展示（spec Scenario 6）

### 场景 6: 一键 AI 总结（FR-009，缓存 + 手动刷新）

1. admin「統計」→ 首次点「一鍵生成總結」→ 10–30s 出叙述总结（提及活跃学生/主题）+ 生成时间戳
2. 切换 Tab 再回来 → **上次总结与时间戳仍在**（缓存生效，未重新调 AI）
3. 点「重新生成」→ 新调用，时间戳更新
4. 总结含 stats 计数且与实际一致；可复制；DeepSeek 故障 → 明确失败提示可重试（缓存保留旧值）

### 场景 7: Top 3 优质问题（FR-011）

1. 「統計」→ Top 3 优质问题卡片：学生名 + 原文 + 所属诗人 + 一句话理由
2. 互动不足 3 条 → 显示实际条数
3. 含敏感词的历史留言**不参与**评估

### 场景 8: 敏感词命中明确提示（FR-012，research D5）

1. 学生端提交「你是個笨蛋」→ 拦截，toast：「留言包含違禁詞「＊＊」，請修改後再發送」（掩码非原文）
2. 追问同样生效
3. **绕过前端**（curl 直调 ai-reply）→ 422 响应含 `hit_word: "＊＊"`（同一掩码规则）
4. AI 输出含敏感词 → 仍替换为安全回复（003 行为不变）

### 场景 9: 学生端 QR（FR-001，research D6）

1. header 出现 ⚙️ 设置按钮 → 点击弹出二维码 modal
2. 手机扫码 → 打开当前环境学生端首页
3. modal 含可复制链接；CDN 加载失败时显示纯链接

### 场景 10: 双环境回归

- staging 全场景 + 生产（上生产后抽查 1/4/5/8）
- 学生端原有流程（留言→AI→追问→切诗人）无回归
- admin 003 功能（留言线程/编辑/违禁词/模板）无回归
