# DeepSeek is the sole AI provider, called only from the Edge Function

All poem-persona replies are generated by DeepSeek, invoked exclusively inside the `ai-reply` Edge Function using a server-side secret. The client never calls the model and never holds the API key.

**Considered options**
- Client calls DeepSeek directly: rejected — leaks the key and breaks the "Security by Default" / "Edge Functions for AI Integration" principles.
- Proxy through Edge Function with swappable providers: heavier; not pursued because one provider meets current needs.

**Consequences**
- Vendor lock-in to DeepSeek's API shape and rate limits. Swapping providers means rewriting the function body.
